# Consent, Recording & DPDP policy (Retail)

## Purpose
Govern the collection, processing and recording of personal data under the Digital Personal Data Protection (DPDP) Act and RBI norms.

## Consent
- Obtain explicit, informed consent before recording a call or using data for analytics or marketing.
- Honour opt-outs; suppress marketing where consent is withdrawn.

## Data handling
- Collect only what is needed; mask PAN / Aadhaar / card numbers; restrict access; retain per policy.
- Customers may request access, correction or erasure (data-principal rights).

## RM guidance
- Confirm consent status before any marketing outreach.
- Do not read sensitive identifiers aloud; reference masked values only.
